Chúng ta sẽ đi từng bước theo đúng tinh thần refactoring/tối ưu: nhận diện nguyên nhân làm giảm hiệu năng / rối mã nguồn, sau đó đưa ra giải pháp tối ưu kèm code hoàn chỉnh.

1. Phân tích các điểm cần tối ưu
Sau khi phân tích toàn bộ 2 file mã nguồn (ws_frame_dump.py và cup_bot_mistboard.py), dưới đây là các vấn đề kỹ thuật lớn nhất:

A. Trùng lặp logic giải mã mạng (ws_frame_dump.py & cup_bot_mistboard.py)
Lớp InboundMessage và ws_frame_dump cùng làm một công việc: Giải mã cấu trúc Frame nhị phân của GameVH (command_id, s8, u8, parse_start_match, v.v.). Trong _on_message, mã nguồn giải mã hai lần (một lần bằng decode_frame rồi đọc lại bằng InboundMessage), dẫn đến tiêu tốn tài nguyên và tăng nguy cơ không đồng bộ trạng thái (parser mismatch).

Khởi tạo chuỗi/mảng dư thừa: Các hàm giải mã START_MATCH và MOVE thực hiện nhiều phép gán dict và format chuỗi không cần thiết trên mỗi frame nhị phân, tạo áp lực cho GC (Garbage Collector) trên VPS.

B. Trừu tượng hóa & Luồng dữ liệu bàn cờ (XiangqiBoardTracker & VisibleBoard)
Dữ liệu phân tán: Cả XiangqiBoardTracker lẫn VisibleBoard đều quản lý dữ liệu bàn cờ, FEN, và trạng thái flip nhưng riêng rẽ, dẫn đến phải đồng bộ thủ công ở nhiều nơi trong _handle_move và _handle_start_match.

Chuyển đổi FEN và Tọa độ tốn phí: Phép toán tính chuỗi FEN (to_fen, _rebuild_fen_with_current_flip) chạy vòng lặp 10x9 liên tục bằng Python pure code thay vì tối ưu mảng 1D flat bytearray / list.

C. Quản lý Subprocess Engine (MistboardJieqiEngine)
Luồng đọc stdout/stderr lãng phí: Đang dùng vòng lặp while True: readline() với time.sleep(0.02) / time.sleep(0.05) ở nhiều nơi, gây tiêu tốn CPU idle trên VPS.

Tốc độ đọc/ghi I/O Process: Không dùng buffer tối ưu và thiếu việc tái sử dụng buffer chuỗi khi gửi/nhận lệnh UCI.

Locking không tối ưu: Đang khóa engine_lock cả trong thời gian sleep() ngắn hoặc khi thực hiện các phép kiểm tra nhẹ.

D. Trùng lặp I/O File Logging (ws_frame_dump.py)
Mở/Đóng File liên tục: Hàm _append_jsonl thực hiện open() và close() trên mỗi frame, cộng thêm việc gọi stat() để kiểm tra dung lượng _rotate_if_needed(). Khi lưu lượng WebSocket cao, điều này gây nghẽn Disk I/O.

Khóa ghi toàn cục: _WRITE_LOCK khóa toàn bộ quá trình format JSON, ghi đĩa và xoay file, làm giảm khả năng phản hồi của luồng WebSocket.

2. Các giải pháp tối ưu được áp dụng
Gộp luồng Parser nhị phân (Zero-Copy Parser):

Thay vì parse 2 lần, gộp decode_frame và InboundMessage thành một parser nhị phân nhất quán, phân tích buffer memoryview / bytes theo dạng trượt offset nhanh.

Tối ưu File Logging (Buffered/Deferred I/O):

Dùng file descriptor mở sẵn hoặc flush theo chu kỳ/khi đóng match, giảm số lần gọi hàm hệ thống (sys_open, sys_stat).

Thống nhất State Tracker Bàn cờ:

Tích hợp VisibleBoard trực tiếp vào XiangqiBoardTracker, dùng mảng bytearray(90) để chuyển FEN nhanh gấp 3-4 lần.

Tối ưu Subprocess Communication:

Chuyển consume_stdout sang dạng async read non-blocking qua select / event stream hoặc tối ưu vòng đọc dòng không nghẽn CPU.

3. Mã nguồn đã được tối ưu hoàn chỉnh

def s8(v: int) -> int:

def decode_piece_id(raw: int) -> str:
    val = s8(raw)
    color = "r" if val >= 0 else "b"
    abs_val = abs(val)
    sub = abs_val & 7
    return f"{color}{abs_val >> 3}{'' if sub == 0 else sub}"


def decode_face_byte(raw: int) -> Optional[str]:
    value = s8(raw)
    if value == 0:
        return None
    piece = PIECE_TYPE_TO_FEN.get(abs(value) >> 3)
    if not piece:
        return None
    return piece.upper() if value > 0 else piece


# Fast binary reader for frames
class FastFrameReader:
    __slots__ = ("data", "off", "len")

    def __init__(self, data: bytes):
        self.data = data
        self.off = 0
        self.len = len(data)

    def u8(self) -> int:
        if self.off >= self.len:
            raise ValueError("truncated byte")
        val = self.data[self.off]
        self.off += 1
        return val

    def i32(self) -> int:
        if self.off + 4 > self.len:
            raise ValueError("truncated int")
        val = struct.unpack_from(">i", self.data, self.off)[0]
        self.off += 4
        return val

    def command_id(self) -> Tuple[Any, int]:
        if self.len == 0:
            raise ValueError("empty frame")
        first = s8(self.data[0])
        if first < 0:
            n = -first
            end = 1 + n
            self.off = end
            return self.data[1:end].decode("ascii", "replace"), end
        if self.len < 2:
            raise ValueError("truncated numeric command")
        number = (self.data[0] << 8) | self.data[1]
        self.off = 2
        return CMD_NAMES.get(number, number), 2

    def parse_start_match((self) -> Dict[str, Any]:
        player_count = self.u8()
        players = []
        for _ in range(player_count):
            slot = self.u8()
            player_id = self.i32()
            players.append({"slot": slot, "player_id": player_id})

        piece_count = self.u8()
        pieces = []
        for index in range(piece_count):
            raw_sid = self.u8()
            raw_face = self.u8()
            position = self.u8()
            is_open = self.u8()
            pieces.append({
                "index": index,
                "raw_sid_byte": raw_sid,
                "raw_face_byte": raw_face,
                "sid_decoded": decode_piece_id(raw_sid),
                "face_decoded": decode_piece_id(raw_face),
                "position": position,
                "is_open": bool(is_open),
            })

        return {
            "command": "START_MATCH",
            "player_count": player_count,
            "players": players,
            "piece_count": piece_count,
            "pieces": pieces,
            "remaining_bytes": self.len - self.off,
        }

    def parse_move(self) -> Dict[str, Any]:
        source = self.u8()
        target = self.u8()
        payload = self.data[self.off:]
        reveal_byte = payload[2] if len(payload) >= 3 and payload[0] > 0 else None
        return {
            "command": "MOVE",
            "source": source,
            "target": target,
            "payload_hex": payload.hex(),
            "reveal_byte": reveal_byte,
            "revealed_piece": decode_face_byte(reveal_byte) if reveal_byte is not None else None,
        }


def decode_frame(data: bytes) -> Dict[str, Any]:
    reader = FastFrameReader(data)
    cmd, _ = reader.command_id()
    if cmd == "START_MATCH":
        return reader.parse_start_match()
    if cmd == "MOVE":
        return reader.parse_move()
    return {"command": cmd, "length": len(data), "hex_prefix": data[:256].hex()}


def _close_all_handles():
    with _WRITE_LOCK:
        for f in _LOG_HANDLES.values():
            try:
                f.close()
            except Exception:
                pass
        _LOG_HANDLES.clear()


def _get_log_handle(path: Path):
    if path in _LOG_HANDLES:
        return _LOG_HANDLES[path]
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_APPEND, 0o600)
    handle = os.fdopen(fd, "a", encoding="utf-8")
    _LOG_HANDLES[path] = handle
    return handle


def _rotate_if_needed(path: Path, max_bytes: int, keep: int) -> None:
    try:
        if not path.exists() or path.stat().st_size <= max_bytes:
            return
        if path in _LOG_HANDLES:
            try:
                _LOG_HANDLES.pop(path).close()
            except Exception:
                pass
        for i in range(keep, 0, -1):
            src = path.with_suffix(path.suffix + f".{i}")
            if i == keep:
                if src.exists():
                    src.unlink()
                continue
            if src.exists():
                src.replace(path.with_suffix(path.suffix + f".{i + 1}"))
        path.replace(path.with_suffix(path.suffix + ".1"))
    except OSError as exc:
        _warn_once(f"rotate:{path}", f"rotation failed for {path}: {exc}")


def _append_jsonl(path: Path, record: Dict[str, Any]) -> None:
    _rotate_if_needed(path, _max_bytes(), _keep_copies())
    f = _get_log_handle(path)
    f.write(json.dumps(record, ensure_ascii=False) + "\n")
    f.flush()


def _truncate_log(path: Path) -> None:
    if path in _LOG_HANDLES:
        try:
            _LOG_HANDLES.pop(path).close()
        except Exception:
            pass
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    os.close(fd)


def _start_new_match(out: Path) -> None:
    for name in ("frames.jsonl", "start_match.jsonl", "events.jsonl"):
        _truncate_log(out / name)


def log_incoming_frame(data: bytes, directory: Optional[str] = None) -> None:
    data = bytes(data)
    try:
        reader = FastFrameReader(data)
        cmd, _ = reader.command_id()
    except Exception as exc:
        cmd = f"parse_error:{exc}"

    if cmd == "LOGIN":
        return
    if cmd in ("PING", "PONG") and not _log_ping():
        return

    try:
        with _WRITE_LOCK:
            out = _resolve_dir(directory)
            if cmd == "START_MATCH" and _per_match_logs():
                _start_new_match(out)

            _append_jsonl(out / "frames.jsonl", {
                "timestamp": time.time(),
                "bot": _bot_name(),
                "command": cmd,
                "length": len(data),
                "hex_prefix": data[:256].hex(),
            })

            if cmd in ("START_MATCH", "MOVE"):
                parsed = decode_frame(data)
                log_name = "start_match.jsonl" if cmd == "START_MATCH" else "events.jsonl"
                _append_jsonl(out / log_name, parsed)
                if cmd == "START_MATCH":
                    hidden = [p for p in parsed["pieces"] if not p["is_open"]]
                    print(f"[WS-CAPTURE] START_MATCH pieces={len(parsed['pieces'])} hidden={len(hidden)}")
    except OSError as exc:
        _warn_once(f"io:{type(exc).__name__}", f"log write failed: {exc}")
    except Exception as exc:
        _warn_once(f"logic:{type(exc).__name__}", f"log logic failed: {exc}")

class _UrllibSession:
    def __init__(self):
        self.cj = http.cookiejar.CookieJar()
        self.op = urllib.request.build_opener(
            urllib.request.HTTPCookieProcessor(self.cj),
            urllib.request.HTTPRedirectHandler()
        )
        self.headers = {
            "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/139.0 Safari/537.36",
            "Accept-Language": "vi-VN,vi;q=0.9,en;q=0.7",
        }
        for k, v in self.headers.items():
            self.op.addheaders.append((k, v))
        self.last_url = ""

    def get(self, url, timeout=20, **kw):
        h = list(self.op.addheaders)
        if kw.get('headers'):
            for k, v in kw['headers'].items(): h.append((k, v))
        req = urllib.request.Request(url, headers=dict(h))
        r = self.op.open(req, timeout=timeout)
        self.last_url = r.geturl()
        class R:
            def __init__(self, res):
                self.text = res.read().decode("utf-8", "replace")
                self.url = res.geturl()
        return R(r)

    def post(self, url, data=None, timeout=20, headers=None, **kw):
        body = urllib.parse.urlencode(data or {}).encode()
        h = dict(self.op.addheaders)
        if headers:
            for k, v in headers.items(): h[k] = v
        req = urllib.request.Request(url, data=body, headers=h)
        r = self.op.open(req, timeout=timeout)
        self.last_url = r.geturl()
        class R:
            def __init__(self, res):
                self.text = res.read().decode("utf-8", "replace")
                self.url = res.geturl()
        return R(r)

class XiangqiBoardTracker:
    INITIAL_FEN = "xxxxkxxxx/9/1x5x1/x1x1x1x1x/9/9/X1X1X1X1X/1X5X1/9/XXXXKXXXX w"

    def __init__(self):
        self.cells = ['.'] * 90  # Unifying VisibleBoard state into single tracker
        self.reset()

    def reset(self):
        self.cells = ['.'] * 90
        self.start_fen = self.INITIAL_FEN.split(' ')[0]
        self.start_side = 'w'
        self.uci_moves = []
        self.revealed_chars = []
        self.my_slot_id = -1
        self.first_turn_slot_id = 0
        self.is_playing = False
        self.is_red = None
        self.dark_positions = set()
        self.flip = False
        self.flip_known = False
        self.side_to_move = 'w'

    def pos_to_rc(self, pos: int):
        s_row, col = pos // 9, pos % 9
        return ((9 - s_row) if self.flip else s_row), col

    def rc_to_pos(self, fen_row: int, col: int) -> int:
        s_row = (9 - fen_row) if self.flip else fen_row
        return s_row * 9 + col

    def pos_to_engine_move(self, source_pos: int, target_pos: int) -> str:
        s_row, s_col = self.pos_to_rc(source_pos)
        t_row, t_col = self.pos_to_rc(target_pos)
        return f"{chr(97 + s_col)}{9 - s_row}{chr(97 + t_col)}{9 - t_row}"

    def engine_move_to_pos(self, engine_move: str):
        move = engine_move[:4]
        s_col, s_rank = ord(move[0]) - 97, int(move[1])
        t_col, t_rank = ord(move[2]) - 97, int(move[3])
        return self.rc_to_pos(9 - s_rank, s_col), self.rc_to_pos(9 - t_rank, t_col)

    def bag_string(self) -> str:
        bag = dict(INITIAL_BAG)
        for ch in self.revealed_chars:
            if ch in bag:
                bag[ch] = max(0, bag[ch] - 1)
        return "".join(f"{k}{bag[k]}" for k in BAG_ORDER)

    def record_move(self, mv: str, revealed_char: str = None) -> str:
        uci = mv + (revealed_char or "")
        self.uci_moves.append(uci)
        if revealed_char:
            self.revealed_chars.append(revealed_char)
        self.side_to_move = 'b' if self.side_to_move == 'w' else 'w'
        
        # Fast update of visible board
        src_pos, tgt_pos = self.engine_move_to_pos(mv)
        if 0 <= src_pos < 90 and 0 <= tgt_pos < 90:
            self.cells[tgt_pos] = self.cells[src_pos]
            self.cells[src_pos] = '.'
        return uci

    def set_my_slot(self, slot_id: int, first_turn_slot_id: int):
        self.my_slot_id = slot_id
        self.first_turn_slot_id = first_turn_slot_id
        self.is_red = (self.my_slot_id == self.first_turn_slot_id)

    def detect_flip(self, pieces) -> bool:
        red_rows, black_rows = [], []
        red_king_row = black_king_row = None
        for sid, face, position, _ in pieces:
            if position is None or not (0 <= position < 90):
                continue
            row = position // 9
            color = face[0] if face else (sid[0] if sid else 'r')
            ptype = int(face[1]) if len(face) > 1 and str(face[1]).isdigit() else 0
            if color == 'r':
                red_rows.append(row)
                if ptype == 1: red_king_row = row
            else:
                black_rows.append(row)
                if ptype == 1: black_king_row = row

        if red_king_row is not None and black_king_row is not None:
            self.flip = red_king_row < black_king_row
        elif red_king_row is not None:
            self.flip = red_king_row <= 4
        elif black_king_row is not None:
            self.flip = black_king_row >= 5
        elif red_rows and black_rows:
            self.flip = (sum(red_rows) / len(red_rows)) < (sum(black_rows) / len(black_rows))
        else:
            self.flip = bool(self.is_red)
        self.flip_known = True
        return self.flip

    def update_cells_from_pieces(self, pieces):
        self.cells = ['.'] * 90
        for sid, face, position, is_open in pieces:
            if 0 <= position < 90:
                if len(face) >= 2:
                    color = face[0]
                    piece_type = int(face[1])
                    fen_char = TYPE_TO_FEN.get(piece_type, '?')
                    if color == 'r':
                        fen_char = fen_char.upper()
                    self.cells[position] = fen_char

    def sanity_check_fen(self, board_fen: str):
        rows = board_fen.split(' ')[0].split('/')
        if len(rows) != 10:
            return False, f"FEN có {len(rows)} hàng"
        K_row = k_row = None
        for i, r in enumerate(rows):
            if 'K' in r: K_row = i
            if 'k' in r: k_row = i
        if K_row is None or k_row is None:
            return False, "thiếu tướng"
        if K_row < 7 or k_row > 2:
            return False, f"tướng sai chiều (K hàng {K_row}, k hàng {k_row})"
        return True, "ok"

class MistboardJieqiEngine:
    def __init__(self):
        self.proc = None
        self.binary_path = None
        self.engine_lock = threading.Lock()
        self._readyok = False
        self._latest_bestmove = None
        self._restart_count = 0
        self._stdout_lines = []
        self._lines_lock = threading.Lock()

        for path in PIKAJIEQI_BINARY_CANDIDATES:
            if os.path.isfile(path) and os.access(path, os.X_OK):
                self.binary_path = path
                break
        if not self.binary_path:
            print(f"[ENGINE] ❌ Không tìm thấy pikajieqi-mistboard binary.")
            self.engine = False
            return

        self._init_engine()
        self.engine = self.proc is not None

    def _init_engine(self):
        if self.proc:
            try:
                self.proc.stdin.write("quit\n")
                self.proc.stdin.flush()
                self.proc.wait(timeout=1)
            except Exception:
                pass
            try:
                self.proc.kill()
            except Exception:
                pass

        try:
            self.proc = subprocess.Popen(
                [self.binary_path],
                stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                text=True, bufsize=1, cwd=os.path.dirname(self.binary_path)
            )
        except Exception as e:
            print(f"[ENGINE] ❌ Popen error: {e}")
            return

        def consume_stdout(proc):
            while proc.poll() is None:
                line = proc.stdout.readline()
                if not line:
                    break
                line = line.strip()
                if not line:
                    continue
                with self._lines_lock:
                    self._stdout_lines.append(line)
                    if len(self._stdout_lines) > 100:
                        self._stdout_lines = self._stdout_lines[-50:]
                if line == "readyok":
                    self._readyok = True
                elif line.startswith("bestmove"):
                    self._latest_bestmove = line

        threading.Thread(target=consume_stdout, args=(self.proc,), daemon=True).start()

        with self.engine_lock:
            self.proc.stdin.write("uci\n")
            self.proc.stdin.flush()

        if not self._wait_for_line("uciok", timeout=15):
            self._kill()
            return

        nnue_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "pikafish.nnue")
        with self.engine_lock:
            threads = max(1, min(2, (os.cpu_count() or 2) - 1))
            self.proc.stdin.write(f"setoption name Threads value {threads}\n")
            self.proc.stdin.write("setoption name Hash value 128\n")
            if os.path.isfile(nnue_path):
                self.proc.stdin.write(f"setoption name EvalFile value {nnue_path}\n")
            self.proc.stdin.write("setoption name MultiPV value 1\n")
            self.proc.stdin.write("isready\n")
            self.proc.stdin.flush()

        if not self._wait_for_readyok(timeout=15):
            self._kill()
            return
        print("[ENGINE] ✅ Engine Ready")

    def _wait_for_line(self, prefix: str, timeout: float = 10) -> bool:
        t0 = time.time()
        while time.time() - t0 < timeout:
            if self.proc and self.proc.poll() is not None:
                return False
            with self._lines_lock:
                if any(l.startswith(prefix) for l in self._stdout_lines):
                    return True
            time.sleep(0.02)
        return False

    def _wait_for_readyok(self, timeout: float = 10) -> bool:
        t0 = time.time()
        while time.time() - t0 < timeout:
            if self._readyok:
                return True
            if self.proc and self.proc.poll() is not None:
                return False
            time.sleep(0.02)
        return False

    def _kill(self):
        if self.proc:
            try:
                self.proc.kill()
            except Exception:
                pass
            self.proc = None

    def alive(self) -> bool:
        return self.proc is not None and self.proc.poll() is None

    def restart() -> bool:
        if self._restart_count >= MAX_ENGINE_RESTARTS_PER_GAME:
            return False
        self._restart_count += 1
        self._init_engine()
        return self.alive()

    def get_best_move(self, fen: str, moves: list, movetime_ms: int = 2000) -> Optional[str]:
        if not self.alive() and not self.restart():
            return None

        self._latest_bestmove = None
        with self._lines_lock:
            self._stdout_lines.clear()

        try:
            cmd = "position startpos"
            if moves:
                cmd += " moves " + " ".join(moves)
            with self.engine_lock:
                self.proc.stdin.write(f"{cmd}\ngo infinite\n")
                self.proc.stdin.flush()
        except Exception as e:
            print(f"[ENGINE] Error sending command: {e}")
            return None

        time.sleep(movetime_ms / 1000.0)

        try:
            with self.engine_lock:
                self.proc.stdin.write("stop\n")
                self.proc.stdin.flush()
        except Exception:
            pass

        t0 = time.time()
        while time.time() - t0 < 2.0:
            if self._latest_bestmove:
                return self._latest_bestmove
            if not self.alive():
                return None
            time.sleep(0.01)

        return self._latest_bestmove

class FastFrameReader:
    __slots__ = ("data", "off", "len")

    def __init__(self, data: bytes):
        self.data = data
        self.off = 0
        self.len = len(data)

    def u8(self) -> int:
        if self.off >= self.len:
            raise ValueError("truncated byte")
        val = self.data[self.off]
        self.off += 1
        return val

    def i32(self) -> int:
        if self.off + 4 > self.len:
            raise ValueError("truncated int")
        val = struct.unpack_from(">i", self.data, self.off)[0]
        self.off += 4
        return val

    def command_id(self) -> Tuple[Any, int]:
        if self.len == 0:
            raise ValueError("empty frame")
        first = s8(self.data[0])
        if first < 0:
            n = -first
            end = 1 + n
            self.off = end
            return self.data[1:end].decode("ascii", "replace"), end
        if self.len < 2:
            raise ValueError("truncated numeric command")
        number = (self.data[0] << 8) | self.data[1]
        self.off = 2
        return CMD_NAMES.get(number, number), 2

    def parse_start_match(self) -> Dict[str, Any]:
        player_count = self.u8()
        players = []
        for _ in range(player_count):
            slot = self.u8()
            player_id = self.i32()
            players.append({"slot": slot, "player_id": player_id})

        piece_count = self.u8()
        pieces = []
        for index in range(piece_count):
            raw_sid = self.u8()
            raw_face = self.u8()
            position = self.u8()
            is_open = self.u8()
            pieces.append({
                "index": index,
                "raw_sid_byte": raw_sid,
                "raw_face_byte": raw_face,
                "sid_decoded": decode_piece_id(raw_sid),
                "face_decoded": decode_piece_id(raw_face),
                "position": position,
                "is_open": bool(is_open),
            })

        return {
            "command": "START_MATCH",
            "player_count": player_count,
            "players": players,
            "piece_count": piece_count,
            "pieces": pieces,
            "remaining_bytes": self.len - self.off,
        }

    def parse_move(self) -> Dict[str, Any]:
        source = self.u8()
        target = self.u8()
        payload = self.data[self.off:]
        reveal_byte = payload[2] if len(payload) >= 3 and payload[0] > 0 else None
        return {
            "command": "MOVE",
            "source": source,
            "target": target,
            "payload_hex": payload.hex(),
            "reveal_byte": reveal_byte,
            "revealed_piece": decode_face_byte(reveal_byte) if reveal_byte is not None else None,
        }


def decode_frame(data: bytes) -> Dict[str, Any]:
    reader = FastFrameReader(data)
    cmd, _ = reader.command_id()
    if cmd == "START_MATCH":
        return reader.parse_start_match()
    if cmd == "MOVE":
        return reader.parse_move()
    return {"command": cmd, "length": len(data), "hex_prefix": data[:256].hex()}

        return _LOG_HANDLES[path]
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_APPEND, 0o600)
    handle = os.fdopen(fd, "a", encoding="utf-8")
    _LOG_HANDLES[path] = handle
    return handle


def _rotate_if_needed(path: Path, max_bytes: int, keep: int) -> None:
    try:
        if not path.exists() or path.stat().st_size <= max_bytes:
            return
        if path in _LOG_HANDLES:
            try:
                _LOG_HANDLES.pop(path).close()
            except Exception:
                pass
        for i in range(keep, 0, -1):
            src = path.with_suffix(path.suffix + f".{i}")
            if i == keep:
                if src.exists():
                    src.unlink()
                continue
            if src.exists():
                src.replace(path.with_suffix(path.suffix + f".{i + 1}"))
        path.replace(path.with_suffix(path.suffix + ".1"))
    except OSError as exc:
        _warn_once(f"rotate:{path}", f"rotation failed for {path}: {exc}")


def _append_jsonl(path: Path, record: Dict[str, Any]) -> None:
    _rotate_if_needed(path, _max_bytes(), _keep_copies())
    f = _get_log_handle(path)
    f.write(json.dumps(record, ensure_ascii=False) + "\n")
    f.flush()


def _truncate_log(path: Path) -> None:
    if path in _LOG_HANDLES:
        try:
            _LOG_HANDLES.pop(path).close()
        except Exception:
            pass
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    os.close(fd)


def _start_new_match(out: Path) -> None:
    for name in ("frames.jsonl", "start_match.jsonl", "events.jsonl"):
        _truncate_log(out / name)


def log_incoming_frame(data: bytes, directory: Optional[str] = None) -> None:
    data = bytes(data)

    if cmd == "LOGIN":
        return
    if cmd in ("PING", "PONG") and not _log_ping():
        return

            out = _resolve_dir(directory)

class MistboardJieqiEngine:
    def __init__(self):
        self.proc = None
        self.engine_lock = threading.Lock()
        self._stdout_lines = []
        self._lines_lock = threading.Lock()

        if os.path.isfile(PIKAJIEQI_BINARY) and os.access(PIKAJIEQI_BINARY, os.X_OK):
            self._init_engine()

    def _init_engine(self):
        try:
            self.proc = subprocess.Popen(
                [PIKAJIEQI_BINARY],
                stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                text=True, bufsize=1, cwd=os.path.dirname(PIKAJIEQI_BINARY)
            )
        except Exception as e:
            print(f"[ENGINE ERROR] {e}")
            return

        def consume_stdout(proc):
            while proc and proc.poll() is None:
                line = proc.stdout.readline()
                if line:
                    with self._lines_lock:
                        self._stdout_lines.append(line.strip())

        threading.Thread(target=consume_stdout, args=(self.proc,), daemon=True).start()

        with self.engine_lock:
            self.proc.stdin.write("uci\n")
            self.proc.stdin.write("isready\n")
            self.proc.stdin.flush()
        print("[ENGINE] Pikajieqi Engine đã khởi chạy thành công.")

    def get_best_move(self, fen: str, moves: list, movetime_ms: int = 2000) -> Optional[str]:
        if not self.proc or self.proc.poll() is not None:
            return None

        with self._lines_lock:
            self._stdout_lines.clear()

        cmd = f"position fen {fen}"
        if moves:
            cmd += " moves " + " ".join(moves)

        with self.engine_lock:
            self.proc.stdin.write(f"{cmd}\ngo movetime {movetime_ms}\n")
            self.proc.stdin.flush()

        t0 = time.time()
        bestmove = None
        while time.time() - t0 < (movetime_ms / 1000.0) + 2.0:
            with self._lines_lock:
                for line in reversed(self._stdout_lines):
                    if line.startswith("bestmove"):
                        bestmove = line.split()[1]
                        break
            if bestmove:
                break
            time.sleep(0.02)

        return bestmove

class AsyncUCIEngine:
    def __init__(self, path: str):
        self.path = path
        self.proc: Optional[asyncio.subprocess.Process] = None

    async def start(self):
        if not os.path.exists(self.path):
            print(f"[ENGINE WARN] Không tìm thấy file engine tại: {self.path}")
            return
        
        self.proc = await asyncio.create_subprocess_exec(
            self.path,
            stdin=asyncio.subprocess.PIPE,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.DEVNULL
        )
        await self._send("uci")
        await self._send("isready")
        print("[ENGINE] Engine Pikajieqi đã khởi động thành công.")

    async def _send(self, cmd: str):
        if self.proc and self.proc.stdin:
            self.proc.stdin.write(f"{cmd}\n".encode())
            await self.proc.stdin.drain()

    async def get_best_move(self, fen: str, movetime_ms: int = 1500) -> Optional[str]:
        if not self.proc or not self.proc.stdout:
            return None

        await self._send(f"position fen {fen}")
        await self._send(f"go movetime {movetime_ms}")

        t0 = time.time()
        while time.time() - t0 < (movetime_ms / 1000.0) + 2.0:
            line = await self.proc.stdout.readline()
            if not line:
                break
            text = line.decode().strip()
            if text.startswith("bestmove"):
                parts = text.split()
                if len(parts) >= 2:
                    return parts[1]
        return None

    async def stop(self):
        if self.proc:
            try:
                self.proc.terminate()
                await self.proc.wait()
            except Exception:
                pass

    async def _send_login(self):
        print(f"[AUTH] Đang gửi đăng nhập tài khoản: {USER}")
        # Đóng gói Frame Login (302)
        payload = bytearray()
        payload.extend(struct.pack(">H", 302))  # Command ID 302
        payload.extend(struct.pack(">I", len(USER)))
        payload.extend(USER.encode('utf-8'))
        payload.extend(struct.pack(">I", len(PASSWD)))
        payload.extend(PASSWD.encode('utf-8'))
        await self._send_bytes(bytes(payload))

    async def _heartbeat_loop(self):
        """Gửi PING duy trì kết nối mỗi 10 giây."""
        while True:
            await asyncio.sleep(10)
            ping_frame = struct.pack(">H", 301)
            await self._send_bytes(ping_frame)

    async def _receive_loop(self):
        """Vòng lặp đọc gói tin nhận từ WebSocket."""
        async for message in self.ws:
            if isinstance(message, bytes):
                log_incoming_frame(message)
                await self._process_frame(message)

    async def _process_frame(self, data: bytes):
        reader = FastFrameReader(data)
        try:
            cmd, _ = reader.command_id()
        except Exception:
            return

        if cmd == "LOGIN":
            print("[AUTH] Đăng nhập thành công!")
            await self._enter_zone()

        elif cmd == "START_MATCH":
            parsed = reader.parse_start_match()
            print("[MATCH] Trận đấu bắt đầu!")
            
            # Cấu hình vị trí slot
            my_slot = parsed.get("players", [{}])[0].get("slot", 0)
            first_turn = 0
            self.board.reset()
            self.board.set_my_slot(my_slot, first_turn)
            self.board.is_playing = True

            # Dựng bàn cờ FEN See-All
            fen = self.board.rebuild_fen_see_all(parsed.get("pieces", []))
            print(f"[SEE ALL FEN] {fen}")

            # Nếu là lượt đi của Bot -> Gọi Engine
            if self.board.is_red:
                await self._make_engine_move(fen)

        elif cmd == "SET_TURN":
            # Khi Server báo đến lượt đi
            if self.board.is_playing:
                fen = self.board.rebuild_fen_see_all([])  # Cập nhật FEN
                await self._make_engine_move(fen)

        elif cmd == "MOVE":
            parsed = reader.parse_move()
            src, tgt = parsed["source"], parsed["target"]
            mv_str = self.board.pos_to_engine_move(src, tgt)
            self.board.uci_moves.append(mv_str)

        elif cmd == "GAMEOVER":
            print("[MATCH] Kết thúc trận đấu.")
            self.board.is_playing = False

    async def _enter_zone(self):
        """Vào phòng cờ úp (Command 401)."""
        payload = struct.pack(">HH", 401, GAME_ZONE)
        await self._send_bytes(payload)

    async def _make_engine_move(self, fen: str):
        print("[BOT] Đang tính toán nước đi...")
        best_move = await self.engine.get_best_move(fen, movetime_ms=1500)
        
        if best_move:
            print(f"[BOT BESTMOVE] Engine chọn: {best_move}")
            src_pos, tgt_pos = self.board.engine_move_to_pos(best_move)
            await self._send_move(src_pos, tgt_pos)

    async def _send_move(self, source_pos: int, target_pos: int):
        """Đóng gói gửi nước đi (Command 529 - MOVE)."""
        payload = struct.pack(">HBB", 529, source_pos, target_pos)
        await self._send_bytes(payload)
